# 写作：从论证功能开始

当前已积累结构性偏好及 P04 首批用户标蓝的语言功能样本，仍不代表完整英语风格。材料优先引言和语言任务按需读取 [专题](material-first-writing.md)；不把个别原文语病、绝对化范围或期刊标签变成通用模板。

## 摘要：相似功能，不同论证起点

共同功能顺序：重要问题 → 精确瓶颈 → 设计/概念 → 机制及证据 → 有条件的代表性结果 → 应用/意义。可合并或调整句子，不限定句数与字数。

| 论文 | 精确瓶颈 | 核心干预 | 机制与结果的联结 | 收束 |
|---|---|---|---|---|
| P01，p1 | 随机多孔体系的孔隙率/曲折度框架未充分表述定向输运 | 结构各向异性与定向孔道 | 引入各向异性；制备和比较支持迁移增强与应变/力改善 | 多聚合物拓展、稳定驱动与软机器人 |
| P02，p1 | 水凝胶和离子弹性体难兼顾兼容性、稳定性及输出 | ChCl–甘油 DES + PVA | 氢键调控的阳/阴离子迁移差异联结压离子响应 | 体外细胞证据与生理信号监测；ECG 是电极采集 |
| P03，p1 | 传统通道关闭态仍有泄漏，门控比有限 | 用水桥可逆形成/断裂切换传输路径 | 两传输模式能垒差 + BC 增强吸脱附，共同实现高 on/off | 固态门控及环境/健康场景 |

写用户摘要时：先定主贡献，再选少量支撑它的结果；每个数值保留条件与量纲，优化配方切换必须可追踪。不要把全部指标堆成清单。

## 引言：不仅是“背景—缺口—本文”

### A / P01：逐步定位未被充分描述的控制变量（p1–3）

软驱动与离子器件 → 电极之外，电解质输运架构也关键 → 水系/离子液体体系与厚度—力学—输运矛盾 → 既有材料和结构工作 → 随机体系的标量描述未显式表示方向性 → 引入各向异性并预告制备、验证、性能与应用。

迁移时说明旧模型在哪个条件下适用、当前结构为何超出描述范围。不要声称旧模型普遍错误，也不要绕很长背景才出现核心变量。

### B / P02：从场景需求筛选材料策略（p1–3）

自供能/生理监测需求 → 机械到电学转换与软界面约束 → 压离子路径 → 水凝胶与离子弹性体的优势/不足 → DES 的相互作用与材料可调性 → 压离子共晶凝胶在该用途的研究机会 → 本文材料、选择性迁移、输出及监测。

迁移时可用“需求—旧体系表现—尚未解决项—材料设计”表梳理。缺口是科学问题或功能组合，不是只说某配方没人做过。对安全与应用的措辞限定在实际测试范围。

### C / P03：从指标瓶颈推出新的调控原则（p1–3）

生物门控的关闭能力 → 人工通道的孔径/电荷调控与残余电流 → 对质子门控更困难 → 将问题重述为传输通路的可逆切换 → 两传输模式的能垒差 → 水桥可控性与固态 HOF 适配性 → HOF/BC 体系及门控结果。

迁移时先说明新原则能解决哪个可测瓶颈，再引出材料为何能承载它。Vincy 所说的“立靶子破靶子”可理解为设定有依据的比较目标；写作中必须公平定义旧方法及适用边界。

### D / P04：先建立材料价值，再收窄到材料核心矛盾（p1）

水凝胶的组织相似性、可调性和多孔价值 → 生物电子需要无缝、动态、持久界面 → 已有导电凝胶能提供的功能及限制 → 半导体可以增添的能力 → 聚合物半导体成网潜力 → 有机溶剂可加工性与传统水凝胶制备不相容 → 既有水加工策略的代价 → 分离成网和水溶胀的新方法。

用户已明确认可其作为注重材料体系时的可选方式，不替代 A/B/C。摘要和标蓝表达的迁移细则见 [专题](material-first-writing.md)。

## Results：让每节成为一个可检查的小论证

常用组织：本节问题/假设 → 对照与测试选择 → 关键观察 → 定量比较 → 机制解释及证据强度 → 回答本节问题并引出下一步。按内容调整，避免所有段落都机械重复六步。

- 以问题组织 SEM、XRD、FTIR 等证据，不按仪器轮流写报告。
- 模拟说明模型、状态和能检验的预测；相关实验用于核对，不把理想模型单独当作实物完整机制的定论。
- 增强后解释可以独立成节，前提是回答了新问题。P03 的 Fig. 5 是解释复合增强，不是再次重复 Fig. 3 的原始水桥机制。
- 优化写清楚目标函数与约束。最大电压、综合输出、导电电极用途可能选择不同配比。
- 文献比较核对驱动、湿度/压力/频率、尺寸/厚度、归一化、响应时间定义与统计。不相同条件用限定性比较，不直接宣布全面领先。
- 应用给出“前文优势 → 此场景所需能力 → 可测结果”。多张照片或波形不等于验证多个独立机制。
- P04 提供“前述材料特征→功能回报”的具体方式：组织级柔软→贴合与异物反应测试；多孔/传质→光作用和体积功能化/传感。遇到低模量，区分模量、强度、韧性和器件完整性，不把柔软写成力学性能整体差。

## 句子、图注与结论

- 当前采用清楚、具体、适度克制的表达；不冒充已学习某作者全部语感。按证据区分观察、支持、提示与证明，避免自动使用 definitive、unprecedented、universal 等强词。
- 连接词承担真实关系：设计动机、对照、因果推断、例外、多目标权衡。不要只替换同义词来模仿表面语言。
- 图注交代体系与条件、各面板内容、单位、误差定义、n 和数据来源；没有的统计信息标缺，不补造。
- 结论回到核心贡献及可迁移边界，不重复完整数据清单，不把示范原型写成成熟医疗或产业能力。

## 写作完成前核对

摘要中的贡献在主图中有无证据？引言提出的瓶颈是否真正解决？关键组分是否在开篇合理预告？机制、优化和应用是否使用不同配方而未说明？比较是否公平？结论强度是否超过证据？
