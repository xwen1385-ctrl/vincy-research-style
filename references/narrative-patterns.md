# 三种叙事模式：按创新与证据选择

本页为基于三篇案例的迁移解释，不是期刊规定。图数与顺序可变。

## A. 结构—参数—器件（P01）

**适合**：创新在孔道、取向、曲折度、结构各向异性或可被测量的结构参数，且有实验支撑结构与性能关系。

逻辑：旧模型的描述边界 → 新结构变量及预测 → 模拟可视化与量化 → 实际结构对照及输运验证 → 器件性能 → 围绕同一结构变量的配方优化 → 优势对应的应用。

图一可以承担一篇小论证：结构差异 → 指标/公式 → 机制预测 → 模拟场 → 时序或统计 → 量化指标与区间总结。没有充分依据时，参数图只能是概念示意，不能包装成定量预测。

P01 特有顺序：先证明结构有效，再优化含量；Fig. 2 用同一聚合物不同制备路线比较，辅以其他聚合物拓展；不是先穷举所有材料。

**风险**：溶剂、工艺、孔隙率和相态可能同时改变，不能仅凭性能改善声称已隔离单一结构因果。公式的符号定义、计算与测量口径须一致。

## B. 需求—材料—输出—解释（P02）

**适合**：价值在材料同时满足多种使用需求，工作原理容易直观展示，材料形成和配比是重要证据。

逻辑：场景及需求冲突 → 工作原理与传统体系比较 → 材料网络、组成、微结构及所需兼容性 → 配比—力学—电输出—负载与耐久 → 文献比较 → 用计算和针对性表征解释选择性输运 → 场景验证。

图一强调“输入是什么、输出是什么、为何需要这个体系”；不用把全部分子机理塞在开篇。图二把材料设计与图一的承诺逐一对应，避免表征目录。图三从不同测试中形成决策，而非把曲线逐条报完。

**多目标优化**：最大输出配方不一定是综合最优或具体应用最优。P02 中 DES30 电压最高，DES50 用于输出评价，DES70 用于 ECG 电极。迁移时用“目标—配方—选择依据”表管理。

**风险**：四张由同一负载扫描派生的曲线不是四个独立验证。细胞活性证据不自动等于完整体内/长期使用安全；电信号采集与自供能发电需分开表述。

## C. 瓶颈—概念切换—验证—增强（P03）

**适合**：创新是新的控制变量或传输路径，能够提出可区分的预测，并有对照证据检验。

逻辑：旧方法受限及所需目标 → 新的调控原则 → 同一体系的两种状态与预测 → 材料可行性及初始响应 → 计算/实验验证关键路径 → 性能增强、优化与文献比较 → 解释增强机制 → 应用。

P03 的重点是借助湿度可逆切换通路，实现低 off 和高 on。不能仅总结为“越快越好”，也不能把低湿度慢态描述成作者要彻底消除的失败状态。

开篇允许预告增强组分，正文再分层展开。纯体系用于建立核心机制，复合体系用于性能增强；不能在摘要/图一隐去最终体系组成。

Fig. 5 这种“增强后再解释”适用于新增干预提出了独立机制问题的情况。若只是重复基本机理，合并更清晰。

**风险**：用比喻替代能垒、迁移或水吸脱附证据；把理想化扩层模型声称为完整复合体系模拟；只提高 on 而忽略 off；把故事顺序当成实验发生顺序。

## 选择与混合

| 当前证据与贡献 | 起点 | 可组合部分 |
|---|---|---|
| 结构参数有预测及验证 | A | B 的清晰场景输入输出，C 的可检验对照 |
| 材料组合解决明确需求冲突 | B | A 的结构定量，C 的机制验证 |
| 新传输/调控原则可被对照检验 | C | A 的参数总结，B 的材料与应用决策 |
| 主要只有性能与组成数据 | 先用 B 或保守的性能叙事 | 把机制列为假说，不虚构模拟或强套 C |

每次选择以当前研究为依据。若混合模式，仍需一个中心结论；不要把三个模式机械串成超长文章。
