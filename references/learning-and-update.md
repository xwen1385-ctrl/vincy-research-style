# 持续学习与更新

本文件是实际维护流程。只有更新到 skill 文件里，后续会话才能继续使用；读过新论文不等于持久学习。

## 新论文进入时

1. 读取文件，核实题名、DOI、版本、物理页码和主图数量。先结合用户指出的欣赏点决定重点。无法访问时标记未核验，不用用户概述冒充原文分析。
2. 图形风格学习必须渲染并查看相关图，不只抽文字。摘要/引言需读相应完整页面，图组结合图注及 Results。记录未读取的补充材料。
3. 给新论文分配未使用的 P 编号，在 `papers/` 添加卡片并更新 `corpus.md`。不复制整篇全文到模型指令；保留外部来源、页码和功能性分析。
4. 对比已有 A/B/C 模式：强化现有模式、增加变体，或有实质差异时新增模式。不要因为期刊名相同就合并。
5. 分别更新叙事、写作、视觉参考中真正改变决策的条目；新例子不必改 `SKILL.md`。避免同一规则多处重复。
6. 规则分“案例观察”“候选”“用户认可”。新样本默认案例；用户明确认可的才进入个人偏好。新的明确指令优先；相互矛盾且影响任务的偏好再询问，不静默覆盖。
7. 用当前任务或小型情景检查规则是否误导。报告新增案例与规则、默认变化、来源定位和待确认项。

## 论文学习卡模板

```markdown
# P编号：短标题
题名 / 作者 / 期刊 / 年份 / DOI / PDF 路径及版本
学习日期；已检查页码；未检查材料

## 用户评价
具体喜欢/不喜欢什么；不要把分析者建议当成用户偏好。

## 原文事实
图号及物理页码 | 主问题 | 关键面板 | 证据类型 | 与前后图关系
摘要功能顺序；引言如何收窄问题；Results 如何推进。
注意配方、状态、对照、比值口径与测试条件。

## 视觉观察
布局、对齐、主次、颜色语义、字体与标注层级。
注明目视估计/实测；实测给出来源坐标系和误差。

## 可迁移解释
规则 ID | 适用条件 | 具体做法 | 来源图/页 | 状态 | 不适用情况

## 未知、冲突与不继承项
无法核验的因果、审稿历史、模型边界、色值等。
```

## 学习新的语言表达样本

在用户明确指出优秀段落后，记录“段落任务—信息顺序—句间关系—可迁移写法—适用条件”。以概括和重新创作的例句为主，不积累长篇原文。新英语示例明确标为自拟；不伪称原文引句。

分别学习摘要压缩、引言缺口、Results 推进、Discussion 权衡、图注信息组织；只有样本真的体现新的规律时才补充。三个材料领域样本不自动代表其他领域的统计写作规范。

## 行为检查案例

这些情景用于检验规则的适用性，不是通过措辞匹配的单元测试。

| 情景 | 应有行为 | 应避免行为 |
|---|---|---|
| 只有配比、力学与输出，无模拟 | 用 B 模式形成暂定主线，说明机制证据缺口 | 为凑 P01 模式编造模拟图或 χ 公式 |
| Vincy 要按第三篇规划五张图 | 说明来源为六图，可按用户五图约束合并，保留关键证据 | 坚持一定六图，或错误声称来源只有五图 |
| 最大电压与稳定/柔顺配比不同 | 明确优化目标、用途与配方切换 | 全文用一个未限定的“最佳配比” |
| 新论文高饱和配色但只喜欢其语言 | 收录语言功能，不改变视觉默认 | 用最新论文颜色覆盖 P03 偏好 |
| 问 P03 Fig. 5 是否审稿加图 | 说明主文不足以判断，若有记录再核实 | 推测后保存为事实 |
| 希望多拆面板表现数据丰富 | 用互补问题分层，说明相关或派生数据关系 | 把一个负载扫描称为四个独立实验证明 |
